# 笔试、面试与 Offer

## 阶段

支持网测/笔试、电话或视频初筛、HR 面、业务/技术面、无领导小组、案例/汇报、终面、背调和 offer 沟通。根据 tracker 当前阶段生成，不重复无关内容。

## 准备包

1. 读取当时提交的 JD、简历、网申答案和前序反馈。
2. 准备 30/60/120 秒自我介绍、岗位要求到真实证据映射、项目深挖、STAR 行为题、真实缺口搭桥和反问问题。
3. 校招补充在线测评、笔试科目、群面、成绩/项目和应届身份问题。
4. 社招补充离职原因、业务结果、管理/协作、薪资期望、到岗期和竞业约束。
5. 央国企补充公告资格、企业认知、岗位动机和结构化面试，但不延伸到公务员/事业编备考。

模拟面试时逐题进行，回答后给出证据、结构、表达和岗位匹配反馈。绝不编造经历。

## Offer 比较

以同一税前口径比较固定现金、浮动奖金、福利、股权、城市成本、工时、成长、稳定性和风险。列出待书面确认的问题。合同或竞业问题只做风险提示，建议必要时咨询专业人士。
