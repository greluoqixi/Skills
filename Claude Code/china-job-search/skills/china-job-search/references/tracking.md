# 跟踪、跟进、报告与提升

## 状态

使用：`discovered`、`shortlisted`、`applied`、`assessment`、`interview`、`offer`、`rejected`、`withdrawn`、`expired`。面试轮次放在 `stage`，不要发明新状态。

## 结果与跟进

记录渠道、时间、来源消息摘要和下一步。无明确时间线且静默约 10 天时可起草一次简短跟进；最多两次，尊重公告时间。面试后可生成 2–4 句感谢信息。所有消息仅为草稿。

用户粘贴邮件、短信或聊天内容时，批量提出 tracker 变更并引用原文；取得确认后再写。冲突信息标记为人工处理，offer 不自动推断为接受或拒绝。

## 报告

使用 `report.py` 生成单文件离线 HTML，展示状态、来源、城市、轨道、匹配分、漏斗和申请表。档案和文档内容不得嵌入报告，只显示文件名或相对路径。

## 技能提升

从高匹配岗位的真实缺口汇总硬技能、领域、工具流程、软技能和证书。只推荐实际检索到的最新资源，记录 URL、检索日期和适用原因。先学依赖和高频关键缺口，低优先级只列出不扩展课程。
