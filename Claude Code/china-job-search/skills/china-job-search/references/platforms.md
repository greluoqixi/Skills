# 中国大陆岗位来源与检索

资料复核日期：2026-08-01。平台页面和访问规则会变化，每次新增来源都重新检查。

| 场景 | 主要来源 | 使用方式 |
|---|---|---|
| 综合社招 | BOSS直聘、智联招聘、前程无忧 | 生成搜索入口与关键词；接收用户粘贴的 URL/JD；不抓登录态搜索页 |
| 中高端/猎头 | 猎聘 | 手动搜索与用户导入；不调用受限查询接口 |
| 技术/校招 | 牛客、企业招聘官网、国家大学生就业服务平台 | 公开搜索结果、笔试日历、用户导入 |
| 实习 | 实习僧、学校就业网、国家大学生就业服务平台 | 公开页面或浏览器辅助 |
| 央国企 | 国聘、国务院国资委与企业官方招聘站 | 优先官方公告，保存报名截止时间与资格条件 |
| 内推/人脉 | 脉脉、校友、公众号、已有联系人 | 只生成搜索提示和沟通草稿，不抓取人员或自动联系 |

## 检索流程

1. 从偏好生成中文岗位同义词、职级词、技能词、城市/区县、行业和排除词。
2. 分社招、校招、实习、央国企轨道查询，优先最近 14 天并记录公告截止时间。
3. 商业平台使用 `site:` 搜索、公开索引或给用户可点击的站内搜索提示；不要绕过安全验证。
4. 对候选结果只在需要时读取详情。URL 获取失败时请用户粘贴文字或截图。
5. 用 `job_store.py` 按规范 URL 或“公司+岗位+城市”去重，并与 tracker 交叉检查。
6. 识别同一岗位跨城市批量发布，只合并并提示，不据此断言诈骗。

## 关键词与渠道策略

- 校招同时搜索“届别 + 校招/秋招/春招/提前批 + 岗位族 + 城市”。
- 实习同时搜索“日常实习/暑期实习/转正实习 + 每周到岗天数 + 时长”。
- 社招加入职级、业务域、技术栈和行业同义词；不要仅依赖职位名称。
- 央国企以官方公告为准，第三方转载只用于发现线索。
- 每个中高匹配岗位生成：BOSS 开场白、邮件/公众号投递正文、内推询问草稿；永不自动发送。

## 新来源准入

检查 robots.txt、服务条款、登录/验证码、公开 URL 稳定性、请求量、输出字段和个人使用限制。认证墙、明确禁止自动访问或需要逆向私有接口的来源只登记为“手动”。
