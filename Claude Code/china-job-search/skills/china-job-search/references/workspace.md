# 工作区与候选人档案

## 初始化

运行：

```bash
python "${CLAUDE_PLUGIN_ROOT}/skills/china-job-search/scripts/workspace.py" init <目标目录>
```

默认目标为当前目录的 `job-search-cn/`。已存在工作区时只补齐缺失的框架文件，不覆盖个人内容。

## 三种档案来源

1. 材料导入：读取用户明确提供的简历、成绩单、证书、作品集、既往申请和推荐信。
2. 简历导入：从一份现有简历提取事实，并逐项标记来源。
3. 访谈：按身份、教育、经历、项目、技能、偏好和约束分轮询问。

确认的新事实必须写入 `profile/candidate.md`。不要把聊天记录当作跨会话事实源。

## 文件边界

- `profile/candidate.md`：可用于申请材料的事实。
- `profile/preferences.md`：目标岗位、城市、薪资、工作方式和 deal-breaker。
- `profile/private.md`：身份证、户籍、政治面貌、健康、照片等敏感字段。默认不读取。
- `search/jobs.json`：标准化岗位库。
- `tracker.csv`：申请漏斗。
- `applications/<company>_<role>/`：岗位原文、评分、材料、面试和结果。

## 中国大陆专用字段

按适用轨道询问，不要一次索取全部字段：

- 校招/实习：毕业年月、最高学历、专业、应届身份、三方协议状态、成绩/排名、英语和职业证书、可实习时间。
- 社招：到岗周期、当前合同与竞业约束、期望城市、最低可接受总包、是否接受出差/加班/外包或派遣。
- 央国企：招聘公告明确要求的毕业窗口、学历形式、专业目录、证书、年龄或政治面貌。只记录公告实际要求。

照片、生日、婚育、户籍和身份证信息不得默认写入简历。岗位表单明确要求时，先解释用途并让用户确认。
