# 中文简历、求职信与网申材料

## 简历

- 使用清晰单栏、真实文本和标准标题；避免进度条、图标代替联系方式、复杂表格和装饰性侧栏。
- 校招生默认 1 页，突出教育、项目/实习、技能和奖项；有经验候选人 1–2 页，突出最近且相关的成果。
- 用“动作 + 场景/任务 + 方法 + 可验证结果”写经历。没有数字就写可核实的范围或产物，不造数。
- 相关性裁剪同时考虑岗位关键词、信息唯一性和申请叙事依赖，不机械删除最早经历。
- 照片、年龄、婚育、身份证、详细住址、政治面貌默认不进入简历。

## 求职信与邮件

只在岗位要求、邮件申请或动机解释确有价值时生成。控制 1 页，先说最强匹配证据，再连接公司真实业务，最后给出到岗/沟通信息。避免空泛热情、套话和过度谦虚。

## 平台开场白

控制 80–200 个中文字符：岗位称呼 + 1–2 个强匹配证据 + 明确意向/到岗信息 + 请求沟通。不要群发口吻，不索要私人联系方式。

## 网申字段

- 自我介绍：现状、最强证据、方向、岗位连接。
- 项目条目：项目名、角色、真实日期、用户/目标、难点、本人贡献、结果。
- 限字问题：提供 3–5 个角度，程序化计数并推荐一版。
- 优缺点：用工作行为和改进措施描述，不用人格标签冒充证据。
- 所有字段与简历、求职信、日期和范围保持一致。

## LaTeX

使用 `assets/latex/resume-cn.tex` 和 `cover-letter-cn.tex`。以 XeLaTeX 编译，默认使用 TeX Live 自带 Fandol 字体，避免依赖用户系统字体。转义 `# $ % & _ { } ~ ^ \\` 等特殊字符。
