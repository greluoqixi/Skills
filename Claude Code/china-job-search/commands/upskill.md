# /china-job-search:upskill

Use the `china-job-search` skill and read `references/tracking.md`.

For one job, compare explicit requirements with the profile. For `all`, aggregate recurring gaps from saved JDs, weighted toward high-fit target roles. Separate hard skill, domain, tooling/process, soft-skill, and credential gaps. Remove anything already evidenced in the profile.

Search for current primary or reputable hands-on resources for critical/high gaps. Record title, direct URL, access cost, checked date, reason, study direction, prerequisite, and realistic time. Never invent resources. Save a dated report and show changes from the previous report.
