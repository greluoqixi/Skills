# Claude Code Extensions

This directory contains installable Claude Code skills and plugins. Each project is self-contained and follows the current Claude Code plugin conventions.

## Available projects

- [claude-project-intelligence](./claude-project-intelligence/README.md) — Project navigation, indexing, and verified bug knowledge support.

## Compatibility and contributions

Each project documents its own runtime and minimum Claude Code version. Keep changes scoped to the relevant project, preserve bilingual navigation, and validate plugin manifests before submitting changes.
