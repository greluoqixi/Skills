# Claude Code 扩展

此目录存放可安装的 Claude Code Skills 和 Plugins。每个项目相互独立，并遵循当前 Claude Code 插件规范。

## 可用项目

- [claude-project-intelligence](./claude-project-intelligence/README.zh-CN.md) — 提供项目导航、索引和经过验证的 BUG 知识支持。

## 兼容性与贡献

各项目分别记录运行时和最低 Claude Code 版本。修改应限制在对应项目内，保持中英文导航同步，并在提交前验证插件 manifest。
