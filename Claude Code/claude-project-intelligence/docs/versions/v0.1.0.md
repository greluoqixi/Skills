## Capabilities

Uses Plugins, Agent Skills, Hooks, custom Subagents, `CLAUDE.md`, path-scoped rules, plugin executables, and Claude Code's LSP tool. It provides deterministic file manifests, semantic module candidates, bounded routing, reviewed BUG knowledge, verification, repair, rebuild, and explicit migrations.

## Not supported

No AST call graph, custom language server, database service, cloud index, embedding/vector database, automatic target-repository test execution, automatic BUG promotion, or wholesale context injection.

## Upgrade and migration

Plugin updates never silently migrate project knowledge. Run doctor and a dry-run migration first; apply only after reviewing the diff. Generated artifacts are rebuilt, while curated fields are preserved. Rollback uses the migration journal.

## Security and testing

The scanner excludes common secrets, binary and oversized files, validates canonical write boundaries, and does not execute repository code. Core tests are offline; public repository tests use fixed commits. Actual platform and Claude Code results will replace target statements before release.
