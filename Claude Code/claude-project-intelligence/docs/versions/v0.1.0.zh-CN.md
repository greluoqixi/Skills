## 能力

使用 Plugins、Agent Skills、Hooks、自定义 Subagents、`CLAUDE.md`、路径级 rules、插件 executable 和 Claude Code LSP。提供确定性文件 manifest、语义模块候选、有预算的路由、审核 BUG 知识、verify、repair、rebuild 和显式迁移。

## 不支持

不提供 AST 调用图、自建语言服务器、数据库服务、云索引、embedding/向量库、自动执行目标仓库测试、自动晋升 BUG 或全量上下文注入。

## 升级与迁移

Plugin 更新不会静默迁移项目知识。先运行 doctor 和 dry-run migration，审核差异后再应用。派生内容可以重建，人工字段必须保留；rollback 使用 migration journal。

## 安全与测试

扫描器排除常见密钥、二进制和超大文件，验证 canonical 写边界，不执行仓库代码。核心测试离线；公共仓库测试固定 commit。发布前以真实平台和 Claude Code 测试结果替换目标声明。
